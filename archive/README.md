# Historical archive

Reserved for preserved snapshots imported from the reference repository.

- Never overwrite or delete an archived snapshot during routine development.
- Record original project path, source commit or archive filename, capture date when known, and SHA-256 checksum.
- Exclude real `.env` files, credentials, private keys, dependency directories, caches, and generated bundles from public archives.
- Keep secret-bearing originals in private storage only. Public Git history is not a secure vault.
- Prefer compressed source snapshots with a manifest over thousands of loose backup files.
